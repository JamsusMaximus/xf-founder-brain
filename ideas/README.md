# Ideas

One file per idea, named `ideas/<short-name>.md`. Copy `_template.md`.

Each file holds: the idea in one line, the ideal customer (ICP), hypotheses, the riskiest assumption, evidence for and against (each with a date and a link to a `calls/` file), and a status.

Statuses: `exploring`, `testing`, `promising`, `paused`, `killed`.

Update the file after every call. When an idea dies, move it to `killed/`. Claude reads this folder every session.
