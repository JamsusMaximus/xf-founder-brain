# Killed ideas

Every killed idea gets a file here, named `<short-name>.md`. Killing ideas fast is the job. Write it up so it is never re-litigated by accident.

Include:
- **What it was:** one line, plus the ICP.
- **The evidence:** calls, tests, numbers, with links to `calls/` files.
- **Why it died:** the specific hypothesis that failed.
- **What carries over:** contacts, insights, a better question, a smaller wedge worth keeping.
- **Would it come back?** What would have to change.

Also add a line to `decisions.md`.
