# Set up the founder brain

Follow `prompts/founder-interview.md` exactly. Mechanics:

1. **Check existing context first.** Read `CLAUDE.md`, `context/founder.md`, `ideas/`, `ideas/killed/`. Tell the founder in a few lines what is already filled and what is a gap. Placeholder text (files saying "Placeholder" or "Not yet captured") counts as a gap.
2. **Never overwrite** a file with real content. Only fill gaps, or add to files. If the founder wants to redo a section, confirm first.
3. **Ask for the LinkedIn PDF (or pasted profile) first**, then summarise it back and confirm.
4. **One question at a time.** If an answer is vague, probe once, then move on.
5. **Never assume the XF programme timeline.** Ask for dates and decision points.
6. **Propose, then save.** After each section show the proposed file content. Save only after approval.
7. Write live ideas to `ideas/<name>.md` from `ideas/_template.md`, killed ideas to `ideas/killed/<name>.md`, background, XF context and goals to `context/founder.md`, and only replace the coaching placeholder in `CLAUDE.md`.
8. Leave sensitive personal matters out unless the founder asks for them in.
9. Finish by listing what exists, what is still thin, and the first customer call to book. Mention `prep-call`.
