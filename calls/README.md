# Calls

Call notes, grades and pre-call briefs land here. This folder is gitignored by default (see `.gitignore`).

Naming (`<person>` is a lowercase-hyphenated name, or a pseudonym if the call is sensitive):
- Raw transcript: `calls/YYYY-MM-DD-<person>.transcript.md`
- Graded note: `calls/YYYY-MM-DD-<person>.md` (this is the file that counts towards your weekly target)
- Pre-call brief: `calls/YYYY-MM-DD-<person>-brief.md`
- Two-person team: add the interviewer's initials, for example `calls/2026-10-14-jane-smith-mk.md`

Any source works: Granola, Otter, Fireflies, Zoom exports, voice-memo transcripts, or typed notes. Paste them or drop the files here, then say "grade my call". Notes without a transcript still get an evidence grade; the craft score needs the questions you asked.

Get consent before recording, and keep sensitive third-party data out or pseudonymised.
