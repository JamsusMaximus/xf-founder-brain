# Calls

Granola notes, call grades and pre-call briefs land here. Past transcripts you paste or drop in this folder are fine too.

Naming:
- Notes: `calls/YYYY-MM-DD-<person>.md` (for example `calls/2026-10-14-jane-smith.md`)
- Pre-call brief: `calls/YYYY-MM-DD-<person>-brief.md`

After a call, notes should capture: who, which idea and hypothesis it tested, what they did in the past (not what they say they would do), the commitment signal if any, and what changes in the `ideas/` file. Then say "grade my call" to run the `customer-discovery-grading` skill: craft score out of 10, evidence strength, and the one question you should have asked.

Calls can contain personal details about other people, so keep your copy of this repo private.
