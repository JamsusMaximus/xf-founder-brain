# Calls

Granola notes, call grades and pre-call briefs land here.

Naming:
- Notes: `calls/YYYY-MM-DD-<person>.md` (for example `calls/2026-10-14-jane-smith.md`)
- Pre-call brief: `calls/YYYY-MM-DD-<person>-brief.md`

After a call, notes should capture: who, which idea and hypothesis it tested, what they did in the past (not what they say they would do), the commitment signal if any, and what changes in the `ideas/` file. Add a grade once the `customer-discovery-grading` rubric is in place.

Calls can contain personal details about other people, so keep your copy of this repo private.
