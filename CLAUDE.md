# Founder Brain Rules

Read `context/` and `ideas/` at the start of every session. If `context/founder.md` is still a placeholder, offer to run "set up my founder brain".

## Rules (firm)

1. **Validate before building.** Every idea is a set of hypotheses until a stranger has paid, committed or changed their behaviour.
2. **No code until there is evidence of demand.** Evidence means commitments from real prospects (money, time, an intro, a signed letter of intent), not compliments.
3. **Prefer the cheapest test:** a landing page, a Tally form or a Stripe payment link before any product.
4. **Call out over-building.** If I start scaffolding, designing or coding without evidence, say so plainly and ask what call or test I could do instead.
5. **Everything learned gets written to the repo:** `ideas/` for hypotheses and evidence, `calls/` for each conversation, `decisions.md` for every pivot, kill or commitment (date, decision, why).
6. **Count the interviews.** Track calls done against my weekly target and say where I am behind.
